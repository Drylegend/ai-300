# Day 1: MLOps Foundation & Architecture

## Overview
Welcome to Day 1 of the Azure MLOps Engineer Associate (AI-300) track. Today's sessions focus on laying the architectural groundwork for enterprise machine learning operations on Microsoft Azure.

### Key Topics Covered
1. **MLOps Lifecycle & Governance**
   - The evolution from ad-hoc data science to standardized, repeatable ML engineering.
   - Core pillars: data drift, continuous integration, continuous delivery (CI/CD), model registry, and governance.

2. **Azure Machine Learning Workspaces**
   - Identity & access management with Microsoft Entra ID and RBAC roles.
   - Storage accounts, Key Vault, Container Registry, and Application Insights integrations.
   - Network isolation strategies: Private Endpoints, virtual networks, and workspace-managed VNets.

3. **Compute Targets & Development Environments**
   - Compute Instances for interactive notebook experimentation.
   - Serverless compute vs. Compute Clusters for scalable distributed training.
   - Curated vs. Custom Environments built on Docker images and conda specifications.
